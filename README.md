## 📍 Classroom Sensor Map
A mobile app built with React Native that displays a map with sensor locations inside a school.
Tracks the user’s location via GPS and calculates distance to each sensor point.

### 🧰 Technologies Used
- React Native
- TypeScript
- React Native Maps
- Geolocation API

### 🎯 Features
- Display map with sensor points in each classroom
- Track user’s real-time GPS location
- Calculate and show distance from user to each sensor
